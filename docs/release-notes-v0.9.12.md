# v0.9.12 — 保存データを保護して起動を継続

設定・発見ファイルを読み込めない場合も、ラボを安全に起動できるようにしました。壊れたファイルや未対応の保存形式はそのまま保護し、そのファイルだけ保存を休止します。正常な設定・発見の利用と保存は継続します。

画面とCLIで保存されない対象をお知らせします。設定を読み込めない場合、活動取得を勝手にONにしません。元ファイルを自動で初期化・削除せず、修復・復元後の再起動で再確認します。

全222テストに合格。保存形式の移行はありません。詳細は[保存データの保護と復旧](storage-recovery-verification.md)を参照してください。
