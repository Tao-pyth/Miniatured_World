# v0.9.10 — PCロック中の休止と復帰

PCをロックすると、ラボの時間と描画、活動の反映を休止します。解除後は同じラボを続けます。手動で一時停止していた状態や、活動取得OFF・ラボ非表示は維持します。

ロックとスリープが重なっても、すべての休止理由が解除されるまで再開しません。停止中の入力や時間をまとめて反映しません。PC状態の確認に失敗した場合は休止を表示して再試行します。

全174テスト、Windows通知経路、実際のPCロックと本人による解除で検証しました。ロック中のWorld停止、解除後の進行、手動一時停止の維持を確認しています。配布exeのコード・素材照合、GUI/CLI起動、通知による停止・復帰も合格しました。詳細は[休止と復帰の検証](session-pause-verification.md)。保存データの移行は不要です。V1全体の性能・互換性の合格判定は引き続き別途行います。
