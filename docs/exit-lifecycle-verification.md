# 終了確認とトレイ操作

「設定 → 一般」の「終了確認」がONなら、ラボやトレイの「終了」で確認画面を表示します。キャンセル・Esc・確認画面の閉じるでは終了せず、同じラボを続けます。確認待ちでも通常の進行を続け、手動の一時停止やPC休止は維持します。OFFなら確認せず終了します。

「トレイへ最小化」がONなら、ウィンドウの閉じるでトレイへ移します。ラボの進行とログ出力は継続し、描画は休止します。トレイから表示すると同じラボを再表示します。この設定がOFF、またはトレイを利用できない場合は終了操作として扱います。隠した後にトレイが使えなくなったことを検知した場合は、操作を戻せるようウィンドウを表示します。

終了を確定すると活動取得と各更新を停止し、保存待ちのデータを既存の保存方針に従って最終再試行して、診断ログ・ウィンドウ・トレイを閉じ、アプリを終了します。壊れたファイルや保存OFF、削除済みデータを勝手に保存再開しません。取消の時点ではこの後始末を実行しません。

検証の時間指定による自動終了、アプリへのプログラム終了要求、OSのセッション終了では確認画面を出しません。確認中に自動終了を迎えた場合も終了できます。強制終了や電源断の保存を保証するものではありません。

## 検証範囲

確認ON/OFF、3つの終了入口、キャンセル/Esc/確認画面閉鎖、重複要求、手動/OS休止、トレイ最小化と不能時の復帰、確認中のduration終了、保存/ログの後始末を自動検証します。実際のQtイベントループを別プロセスで動かし、確認後と無対話終了でプロセスが終了することも確認します。Windows配布版は表示が消えたことに加えて親子プロセス終了を検証します。OS終了はQt境界の注入試験とし、利用者のPCを強制サインアウトしません。

全自動テスト428件成功、Windows配布版の終了・取消・トレイ復帰7経路を確認しました。各終了で親子プロセスが終了し、取消ではログが続き、最小化から同じラボへ戻れることを検証しています。ファイルのシンボリックリンク作成1件はWindows権限によりスキップしています。
