# v0.9.16 — 設定・発見を確認して削除

「設定 → データ」に、発見、設定、設定と発見の削除を追加しました。確認後に実行し、古い内容が次の更新や終了時に再保存されることを防ぎます。削除した種類の保存はOFFになり、利用者がONにすると再開できます。

ラボは続き、正常なもう一方の保存を維持します。壊れたファイルも、明示的に削除を確認した場合だけ削除できます。使用中のファイルなどで失敗した場合は対象別に結果を表示し、再操作できます。

設定形式の移行はありません。キャッシュ・診断ログ・全アプリデータの一括削除は継続課題です。[使い方と検証](data-deletion-verification.md)を参照してください。

自動テスト371件、Windows配布アプリの削除4ケース、保存保護8ケース、保存回復3ケース、時間進行21ケースと休止・復帰の回帰を確認しました。
