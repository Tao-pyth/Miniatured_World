# v0.8.0 Release Notes

`v0.8.0` はMVP Release Candidate本体ではなく、MVP RC判定に必要な材料を揃えるRC準備版です。

## 追加

- Windows実活動Provider `windows-global` を追加。
- Windows実活動Providerを `--activity-provider windows-global` から選択可能にした。
- PyInstaller exeビルド手順 `scripts/build_windows_exe.ps1` を追加。
- exeから利用できる安定性検証ログ出力 `--stability-log` を追加。
- MIT Licenseを追加。
- `v0.8.0` 向けのプライバシー監査、8時間安定性テスト、高DPI、マルチモニター、Windows互換性の手動検証手順を追加。

## 方針

- サポート方針は個人開発の実験版としてGitHub Issueのみ。
- 外部通信は将来導入余地を残すが、`v0.8.0` では未実装・無通信。
- Low-Level Hookは既定採用しない。

## 既知制限

- OSレベルで保証された完全クリック透過は未対応。
- インストーラー、コード署名、自動更新は未対応。
- 高DPI、マルチモニター、アンチチート搭載ゲームとの互換性は完全保証しない。
- 8時間安定性テストはユーザー実機での記録が必要。
