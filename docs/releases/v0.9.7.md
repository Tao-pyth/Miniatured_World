# v0.9.7 活動取得の説明と既存ON/OFFの引き継ぎ

既存ユーザーは活動取得のON/OFFをそのまま引き継ぎ、ラボ上部に説明を表示します。「説明を閉じる」を押しても取得設定は変わりません。旧ONを同意履歴として記録することもありません。

新規GUIでは、実活動の取得を始める前に「取得する」「取得せずに使う」「終了」を選べます。取得しない場合もラボは動き、後から設定・トレイで取得を再開できます。閉じる・Escapeで終了した場合、保存先を作りません。

設定と発見は保持します。`--ephemeral` の無保存、明示demo/none、非対話CLIも継承します。歩行・手元の連続動作・素材は変更していません。

全135テストが合格。[画面・使い方・検査範囲](https://github.com/Tao-pyth/Miniatured_World/blob/v0.9.7/docs/activity-notice-verification.md)を参照してください。V1全体の合格判定は含みません。
