# v0.9.3 前景をドット絵で統一

少女・釜・本・素材かご・トレーを再制作しました。高解像度の小道具と拡大した人物が混在していた表示を、共通64色・同じピクセル単位へ統一しています。

従来版、共通2倍、共通3倍を比較し、床の余白と作業道具の読みやすさを保つ2倍を採用しました。少女は帽子・ゴーグル・衣装などの特徴を引き継ぎ、作業ポーズでは釜へ手を伸ばします。釜本体を全コマで共通にし、湯気と粒子を動かします。

素材到着→本確認→取り出し→調合→完成品配置の動作を維持。手元と完成品の経路を新サイズに合わせました。入力取得・素材計算・発見・保存は変更していません。

検証: 65テスト、40素材の共通パレット/透過/寸法、全作業段階の2×2ピクセル単位、3画面寸法のQt描画、Windows GUI/CLI、wheel/exe同梱を確認。公開後の再取得・SHA256・起動結果はOODA Act記録へ保存します。

配布物: MiniaturedWorld.exe、動作GIF、静止PNG。原画と変換スクリプトもリポジトリに保存しています。自由歩行原画、新たな8時間運転、V1全体の合格判定は含みません。
