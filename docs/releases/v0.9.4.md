# v0.9.4 道具の間を歩く少女

少女に8コマの歩行モーションを追加しました。本・素材かご・釜・トレーへ向きを変えて歩き、到着してから作業します。移動距離に足運びを合わせ、短い移動でも自然に作業へつなぎます。

既存の64色・2倍ドットへ素材を統一し、顔・帽子のコマ間の揺れを抑えました。一時停止や非表示からは同じ位置・姿勢で再開します。

74テスト、左右8コマと全作業段階の3画面寸法でのQt描画を確認しました。原画と整形スクリプト、全体GIF、歩行拡大GIFを同梱・保存しています。wheel/exeの全素材同梱とWindows起動、公開物再取得はOODA Act記録へ残します。

配布物: MiniaturedWorld.exe、全体PNG/GIF、歩行拡大GIF。自由散策・経路探索・V1全体の合格判定は今回に含みません。
