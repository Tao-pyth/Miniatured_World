# v0.8.1 Release Notes

`v0.8.1` は、`v0.8.0` RC準備版にGUIあり8時間安定性検証を追加する小さな検証リリースです。

## 追加

- GUI起動時にも `--stability-log` でJSONL安定性ログを出力できるようにした。
- GUI起動時にも `--duration-seconds` で指定時間後にcompletedを記録して自動終了できるようにした。
- GUI起動時にも `--tick-interval-ms` をQt timerとruntime tickへ反映するようにした。
- 手動終了時は `cancelled` を記録するようにした。
- GUIあり8時間安定性検証手順と有効な実施結果を追記した。
- PySide6 6.10系で作成したexeがGUI起動に失敗するため、配布ビルドは確認済みのPySide6 6.9系へ固定した。

## 既知制限

- MVP RC合格宣言ではありません。
- PySide6 6.10系で作成したexeはGUI起動に失敗するため、v0.8.1の配布ビルドではPySide6 `>=6.7,<6.10` を要求します。
- OSレベルで保証された完全クリック透過は未対応です。
- インストーラー、コード署名、自動更新は未対応です。
- 高DPI、マルチモニター、アンチチート搭載ゲームとの互換性は完全保証しません。

## 日本語説明（初心者向け）

このリリースでは、実際にGUIウィンドウを出した状態でも8時間安定性検証を行えるようにしました。`--no-ui` の検証では見えない、Qtの画面更新やタイマー処理を含めたメモリ使用量を確認できます。

最初の8時間ログはexeがGUI起動に失敗してCLIへ切り替わった状態の記録だったため、GUIあり検証としては無効化しました。その後、PySide6 6.9.3で作成した単体exeでGUI短時間smokeと8時間実機検証をやり直し、完走を確認しました。
