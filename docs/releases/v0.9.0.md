# v0.9.0 小さなラボラトリー

## 概要

V0.9.0では、ユーザー向け体験を「箱庭世界」から「小さなラボラトリー」へ切り替えました。

PC活動に応じて素材が届き、錬金術師の女の子と錬金釜が小さなラボ上で反応する、デスクトップ実験マスコットとして表示します。

## 変更点

- メイン画面名を「ラボ」へ変更。
- ウィンドウタイトルとCLI summaryを「小さなラボラトリー」へ変更。
- ChatGPT生成の基準背景画像を同梱。
- 背景、錬金釜、キャラクター、エフェクト、UIを別レイヤーとして描画。
- キャラクター状態 `idle` / `work` / `success` / `failure` / `rest` を追加。
- 錬金釜状態 `idle` / `receive` / `react` / `success` / `failure` を追加。
- 素材流入、反応光、煙の最小エフェクトを追加。

## プライバシー

V0.9.0でも、入力文字列、キー入力列、マウス座標、Window Title、画面キャプチャ、クリップボード内容は保存・送信しません。

PC活動は、抽象化された活動特徴として素材供給や実験反応へ変換します。

## 既知制限

- 内部モジュール名や一部コマンド名には、互換性維持のため `world` / `miniatured-world` が残ります。
- 初期表示はQt描画による最小アニメーションです。専用スプライトシートは今後の候補です。
- 背景画像は1280x853のため、表示領域に合わせて中央クロップされます。
