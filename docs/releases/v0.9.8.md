# v0.9.8 起動ごとに新しいSeedでラボを生成

GUI・CLIとも、`--seed` を省略すると起動ごとに新しいseedを生成します。再現したい場合は `--seed 20260825` などを指定してください。0や負数もこれまでどおり使えます。

旧版で省略時の固定条件を使っていたCLIコマンドには、`--seed 20260825` の追加が必要です。同じWorld結果の再現には、seedに加えて同じ活動入力も必要です。

既存の活動ON/OFF・説明状態・設定・発見を維持します。ドット絵、歩行、手元動作、World内部の処理は変更していません。

全148テストが合格。[使い方と検証](https://github.com/Tao-pyth/Miniatured_World/blob/v0.9.8/docs/session-seed-verification.md)。V1全体の合格判定は含みません。
