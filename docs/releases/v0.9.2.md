# v0.9.2 小さなラボの配置と作業連携

右奥の机・椅子を浅い壁面本棚へ置き換え、窓・照明・画風と床の余白を維持しました。本、素材かご、完成品トレーを独立した道具として近接配置しています。

小道具を含めた3案を比較して人物1.4倍・釜1.3倍を採用。人物5ポーズと釜32コマの白縁・足元・輪郭の揺れを補正し、顔・服・瓶の明部を保持しました。

素材到着→本の確認とページめくり→素材取り出し→調合→完成品配置が1巡11秒でつながります。連続到着をまとめ、一時停止・非表示・再開にも対応します。完成品は表示用の小瓶で、素材消費や発見のルールは変更していません。

検証: 63件のテスト、3画面寸法のQt描画、全37枚の素材検査、wheelとexeの素材同梱、Windows GUIとCLIの起動確認。公開後の再取得・ハッシュ照合・起動結果はOODA Act記録へ残します。

配布: `MiniaturedWorld.exe`、動作GIF、静止PNG。インストーラー・コード署名・自由歩行・新たな8時間検証は含みません。MVP全体の合格判定は別途扱います。
