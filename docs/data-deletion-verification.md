# 設定・発見の削除

「設定 → データ」から、発見データ、設定、または設定と発見データを削除できます。確認画面の「削除する」を押すと実行します。「キャンセル」とEscでは削除しません。削除は元に戻せません。

| 操作 | 削除後 |
|---|---|
| 発見データを削除 | 発見一覧を空にし、発見の保存をOFFにする。当回の既存発見は一覧へ戻さない |
| 設定を削除・初期化 | 設定を初期化し、設定の保存と活動取得をOFFにする。発見の保存の選択は保持する |
| 設定と発見データを削除 | 上の両方を実行し、それぞれの結果を表示する |

現在のラボは続き、手動停止やPC休止は維持します。削除後も新しい発見は一覧に表示されます。保存を再開したい場合は「発見を保存」「設定を保存」をONにしてください。OFFの間は、他の設定を変更しても削除した設定ファイルを作り直しません。次回起動時に設定ファイルがなければ、活動取得の説明から選び直せます。

壊れたファイルや、この版で読めない形式も、確認して削除した場合に限り保護を解除します。自動で初期値を書き込むことはありません。

## 削除できなかった場合

使用中などで削除できない場合は、未完了の対象を表示します。古い保存待ちデータの再保存を止め、正常なもう一方の保存とラボは続けます。対象を使っているアプリを閉じてから、同じ削除操作をもう一度行ってください。削除に失敗した種類は、保存チェックだけを切り替えても再保存しません。

同時削除で片方だけ成功する場合もあります。画面に対象別の結果を表示します。成功したデータを元へ戻すことはできません。

## 対象範囲

選択中の保存先にあるsettings.json、discovery.json、およびそれぞれの保存用一時ファイルが対象です。一時ファイルはアプリが使用したパス、または「.settings.json.8文字.tmp」「.discovery.json.8文字.tmp」の予約名に限定します。未知のファイルやフォルダ全体を削除しません。

この版では、キャッシュ・診断ログ・すべてのアプリケーションデータの一括削除は含みません。これらは仕様上の残件として継続します。一時実行（--ephemeral）では保存先を読み書きしないため、永続データの削除ボタンを無効にします。同じ保存先を複数のアプリ実行で共有した場合、他の実行が再保存することまでは防ぎません。

## 検証

確認キャンセル、個別・同時削除、部分失敗、保存待ちからの復活防止、旧発見の再出現防止、明示した保存再開、壊れた/未対応形式、未知ファイル保持、一時実行を確認します。Windowsの実ファイル共有制限による削除失敗と解除後の再操作、公開exeのUI操作も検証対象です。開発試験は人工データだけで行います。
