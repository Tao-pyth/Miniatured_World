# v0.9.10 PCロック中の休止

Windows GUIはPCロック中にWorldの時間、描画、活動の反映を止めます。解除すると同じラボを続けます。手動で一時停止していた場合は停止したままです。活動取得OFF、ラボ非表示、Seed、発見、保存先は変更しません。停止中の時間や入力をまとめて反映することもありません。

ロックとスリープが重なった場合は、両方から復帰してから続けます。ウィンドウを隠す場合の継続、閉じてトレイから戻す場合の復帰は従来どおりです。CLIの再現実行はOS状態と連動しません。

PC状態を確認できない場合は「PC状態による休止中」と表示します。ラボ状態の説明には再試行中であることを表示し、5秒ごとに再試行します。手動の再開操作でOSの休止条件を解除することはありません。

診断ログは検査時間中のサンプルを記録し続け、自動休止を `system_paused` で区別します。診断の時間指定はWorld時間ではなく従来のサンプル数の条件です。ウィンドウを閉じた際の診断中止も継承します。

## 検証

- 全174テスト合格。手動状態維持、重複/複数理由、終了後の非再開、活動バッファ破棄、未生成Provider、登録/照会失敗と回復を含みます。
- Windows 11のネイティブ受信窓へロック/解除・休止/復帰通知を送り、Worldと描画の停止、同じセッションの復帰、画面の閉じる/表示モード変更後の通知受信を確認しました。
- 2026-09-12に実際のWindowsロックと本人による解除を実施しました。ロック中192回の観測でWorld時刻13.745が不変、解除後21.02へ進行しました。同時に確認した手動一時停止中のラボは時刻0と停止状態を維持しました。
- 配布exeの43モジュールと184素材、wheelの228ファイルがソースに一致しました。GUI一時実行15.741秒、Windows実活動GUI30.685秒、CLI5フレームが正常完了しました。exeの通知試験でもロック相当の休止中2.0を維持し、解除後3.4へ進行しました。電源通知の注入は実S3スリープと区別します。
