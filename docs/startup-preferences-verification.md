# 起動設定とウィンドウ位置

設定画面の「一般」で、表示位置の復元とログイン時の起動登録を選べます。

## 表示位置を復元する

「表示位置を復元」と「データ → 設定を保存」がONの場合、通常ウィンドウの位置とサイズを保存し、次の起動で復元します。移動中の保存はまとめて行い、終了時とトレイへ隠す前にも保存します。

最大化・最小化・デスクトップ表示の一時的な配置は、通常位置を上書きしません。以前の画面を外した場合は利用できる画面へ戻します。小さい画面では内容をスクロールして、ラボや設定を操作できます。

復元OFF、設定の保存OFF、一時実行では位置を保存しません。設定を削除した場合も、保存を明示的にONにするまで作り直しません。設定ファイルが破損している場合はその原本を保護し、正常な発見データの保存は続けます。

保存対象はこのアプリ自身のウィンドウ配置です。マウス座標、他のアプリ、ウィンドウタイトルを記録する機能ではありません。

## Windowsへの自動起動登録

「ログイン時に起動 → 登録する」をONにすると、現在のWindows利用者について、現在の保存先を使う起動登録を作成します。OFFで解除します。設定画面には実際の登録状態を表示します。以前の版でONを保存していても、その値だけで登録を作ることはありません。

登録はWindows側へ保存するため、「データ → 設定を保存」がOFFでも保持されます。「設定を削除」「設定と発見を削除」「全データを削除」では起動登録も解除します。解除できない場合は設定を残し、削除結果へ表示します。発見やログなど、ほかの対象は個別に処理します。

Windowsの設定やタスクマネージャーで無効にした場合、登録済みでも起動しません。Windows側の選択をアプリが自動で戻すことはありません。登録後すぐに起動する機能ではなく、次のログインが対象です。起動の時刻はWindowsの判断で遅れる場合があります。

配布exeは置いた場所から起動します。exeを移動した場合は、アプリで一度OFFにしてからONにしてください。Pythonから使う場合は、GUIの依存関係を含めてインストールした環境が必要です。作業フォルダや一時的な環境変数だけで読み込めるソースは登録しません。一時実行では登録できません。

パスが長すぎる場合や登録に失敗した場合は、理由を表示します。確認できない状態は中間表示となり、ON/OFFを決めつけません。「登録状態を再確認」で確認し直せます。所有を確認できない登録は、ほかのアプリの登録を壊さないため変更しません。

## 互換性

設定ファイルへ任意の`window`項目を追加しています。これまでの設定は引き続き読み込めます。v0.9.18以前へ戻すと、新しい項目を未対応として設定ファイルを保護する場合があります。自動で項目を削除する移行はしません。旧版へ戻す必要がある場合は、変更前の設定のバックアップを使用してください。

旧版にはWindowsの起動登録を解除する処理がないため、旧版へ戻す前にv0.9.19で登録をOFFにしてください。v0.9.19を起動できない場合は、Windowsのスタートアップ設定で無効にできます。

自動起動は保存先ごとのWindows登録です。別の保存先で動くアプリの登録を、この保存先のデータ削除で解除することはありません。exeやPython環境を削除する前に、使用した保存先で登録をOFFにしてください。

## 検証状況

自動テストは506件合格、1件スキップ（Windowsのファイルシンボリックリンク権限）でした。位置の再起動復元、表示モード変更、人工的な画面縮小時の操作、保存停止・削除・破損保護を確認しました。デスクトップ表示で起動した場合も、通常表示へ戻すと保存した通常位置を使います。

Windows実機の配布exeで、位置と保存境界の8ケース、終了7ケース、データ削除6ケース、破損保護8ケース、書込み回復3ケース、時間進行21ケース、休止・復帰通知とトレイ操作を確認しました。日本語・空白を含む専用試験先で自動起動登録を作り、そのコマンドを異なる作業フォルダから実行してGUI起動・正常終了・同じ保存先への位置保存を確認しました。設定・設定と発見・全データの3種類の削除では、取消時の登録維持と確定時の解除を確認し、試験用の登録が残らないことも確認しました。

v0.9.18の配布exeで新しい設定を読み込ませる試験では、設定原本を変更せず、正常な発見データの保存を継続しました。

物理的なログアウト・再ログインは行っていません。休止通知の試験はアプリ自身へ通知を送る方法で、物理的なロック・スリープ操作とは区別しています。実際の全モニター構成や4段階のDPIを網羅した検証でもありません。公開後の再取得・照合結果はリリース記録へ残します。
