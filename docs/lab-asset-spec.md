# ラボ素材・アニメーション制作仕様

v0.9.4の前景は、少女・釜・本・かご・トレーの48枚を共通64色のドット絵として制作する。背景の窓・照明・本棚・画風はv0.9.2から保持する。

## 共通ピクセル仕様

| 素材 | 論理PNG寸法 | 接地基準 | 舞台での描画寸法 |
| --- | --- | --- | --- |
| 少女5ポーズ＋歩行8コマ | 128×128 | y=120 | 256×256 |
| 釜4系列×8コマ | 96×112 | y=104 | 192×224 |
| 本/書見台 | 48×68 | 下端 | 96×136 |
| かご | 52×28 | 下端 | 104×56 |
| トレー | 48×16 | 下端 | 96×32 |

全PNGはRGBAでalphaは0または255、色は同梱 `sprites_manifest.json` の64色以内。人物/釜は4px以上の透明余白を持つ。色・寸法・原画と成果物のSHA256をmanifestへ記録する。

前景を640×427の論理ピクセル面へ描画して1280×854へ最近傍2倍合成し、1280×853舞台の末尾1行は表示範囲で切る。全景をウィンドウへ同じ倍率で収め、前景内で個別に高解像素材を拡縮しない。ページ・素材・完成品・影も同じピクセル面を使う。

## 配置と作業

`app/lab_layout.py`を正本に、釜(510,730)、本(848,692)、かご(660,766)、トレー(788,758)、少女の待機(694,696)を接地位置とする。作業位置は釜(672,684)、本(724,696)、かご(728,726)、完成品(734,706)。

到着→本確認→取り出し→調合→完成品配置→復帰を1巡11秒で表す。完成品の経路は本の左側を通る。少女は待機/作業/成功/失敗/休憩の5ポーズと歩行8コマ、釜は待機/受取/失敗/成功の4系列を8fpsで再生する。釜の本体は全コマ共通で、上部の湯気と粒子だけを動かす。

一時停止・非表示・他タブ・終了で描画時計を止める。表示からWorld/Activity/保存を変更しない。連続到着を次の1巡へまとめる。

歩行は舞台座標で80px/秒、左右一巡48px。移動距離に比例してコマを選び、移動中は本・素材・完成品の操作を待つ。到着後の時間を0〜1へ正規化して操作する。歩行中の一時停止ではそのコマと接地位置を保持する。

## 再現

開発用依存は `pip install -e ".[ui,dev,art]"`。

```powershell
.venv/Scripts/python.exe scripts/build_pixel_assets.py --output logs/walking-v0.9.4/repro
.venv/Scripts/python.exe scripts/build_walk_sprites.py --output logs/walking-v0.9.4/repro
.venv/Scripts/python.exe scripts/render_walk_preview.py
.venv/Scripts/python.exe scripts/compare_lab_layouts.py
.venv/Scripts/python.exe scripts/render_lab_workflow.py
.venv/Scripts/python.exe -m pytest
```

生成原画とプロンプトは [art/pixel-v0.9.3](../art/pixel-v0.9.3/README.md)。歩行の原画とプロンプトは [art/walking-v0.9.4](../art/walking-v0.9.4/README.md)。上記整形の出力先は `logs/walking-v0.9.4/repro` であり、自動で現行素材を上書きしない。目視・検査後にPNG48枚とmanifestをassetsへ反映する。旧シート切り出し/白縁補正スクリプトは過去版再現用で、現行素材へ実行しない。

## 検証と制限

[構図比較と検証](pixel-art-verification.md)を参照。実デスクトップや他アプリは撮影しない。プレビューは合成したデモ状態だけを描画する。自由散策、高DPI/複数モニター保証、新たな8時間運転は今回の範囲外。
