# ラボ素材・アニメーション制作仕様

v0.9.5の前景は、少女・釜・本・かご・トレー・手マスク・瓶の180枚を共通64色のドット絵として制作する。背景の窓・照明・本棚・画風はv0.9.2から保持する。

## 共通ピクセル仕様

| 素材 | 論理PNG寸法 | 接地基準 | 舞台での描画寸法 |
| --- | --- | --- | --- |
| 少女5ポーズ＋歩行8＋運搬歩行8＋手元61コマ | 128×128 | y=120 | 256×256 |
| 手マスク61枚 | 128×128 | 人物と同じ | 256×256 |
| 空瓶・内容入り瓶 | 24×32 | 底点(12,24) | 48×64 |
| 釜4系列×8コマ | 96×112 | y=104 | 192×224 |
| 本/書見台 | 48×68 | 下端 | 96×136 |
| かご | 52×28 | 下端 | 104×56 |
| トレー | 48×16 | 下端 | 96×32 |

全PNGはRGBAでalphaは0または255、色は同梱 `sprites_manifest.json` の64色以内。人物/釜は4px以上の透明余白を持つ。色・寸法・原画と成果物のSHA256をmanifestへ記録する。

前景を640×427の論理ピクセル面へ描画して1280×854へ最近傍2倍合成し、1280×853舞台の末尾1行は表示範囲で切る。全景をウィンドウへ同じ倍率で収め、前景内で個別に高解像素材を拡縮しない。ページ・素材・完成品・影も同じピクセル面を使う。

## 配置と作業

`app/lab_layout.py`を正本に、釜(510,730)、本(848,692)、かご(660,766)、トレー(788,758)、少女の待機(694,696)を接地位置とする。作業位置は釜(630,690)、本(770,686)、かご(714,744)、完成品(734,726)。従来位置から48舞台px以内の調整で、家具は動かさない。

到着→本確認→取り出し→調合と回収→完成品配置→復帰を約16.2秒（16,217ms）で表す。到着後の4作業は1.8/2.2/3.2/2.2秒。61の表示枠に44種類の全身原画を使い、接触・保持を表示時間で調整する。完成品の経路は本の左側を通る。少女は従来5ポーズ、歩行8、運搬歩行8、手元61コマを持つ。釜は待機/受取/失敗/成功の4系列を8fpsで再生する。釜の本体は全コマ共通で、上部の湯気と粒子だけを動かす。

一時停止・非表示・他タブ・終了で描画時計を止める。表示からWorld/Activity/保存を変更しない。連続到着を次の1巡へまとめる。

歩行は舞台座標で80px/秒、左右一巡48px。移動距離に比例してコマを選び、移動中は本・素材・完成品の操作を待つ。到着後は手元コマの保持時間と接触イベントで操作する。歩行中の一時停止ではそのコマと接地位置を保持する。

## 再現

開発用依存は `pip install -e ".[ui,dev,art]"`。

```powershell
.venv/Scripts/python.exe scripts/build_pixel_assets.py --output logs/hand-motion-v0.9.5/repro
.venv/Scripts/python.exe scripts/build_walk_sprites.py --output logs/hand-motion-v0.9.5/repro
.venv/Scripts/python.exe scripts/build_hand_sprites.py --adopt --output logs/hand-motion-v0.9.5/repro
.venv/Scripts/python.exe scripts/compare_lab_layouts.py
.venv/Scripts/python.exe scripts/render_lab_workflow.py
.venv/Scripts/python.exe -m pytest
```

生成原画とプロンプトは [art/pixel-v0.9.3](../art/pixel-v0.9.3/README.md)。歩行の原画とプロンプトは [art/walking-v0.9.4](../art/walking-v0.9.4/README.md)。上記整形の出力先は `logs/hand-motion-v0.9.5/repro` であり、自動で現行素材を上書きしない。`--adopt` は指定先の既存manifestへ手元素材を統合する指定で、上記では製品assetsを書き換えない。180 PNGと2 JSONを再現し、継承する背景2点を含めた配布素材は184ファイル。旧シート切り出し/白縁補正スクリプトは過去版再現用で、現行素材へ実行しない。

## 検証と制限

[手元の動作と検証](hand-motion-verification.md)を参照。実デスクトップや他アプリは撮影しない。プレビューは合成したデモ状態だけを描画する。自由散策、高DPI/複数モニター保証、新たな8時間運転は今回の範囲外。

## 手元と受け渡し

`hand_motion.json` にコマ時間、接地、両手首、把持点、手マスク、容器角度、接触イベントを持つ。瓶の把持点(12,10)、口(12,8)、底(12,24)を接触判定へ使う。かご・釜・トレーの前縁と、全身原画から画素を変えずに抜いた指マスクを部分合成する。

表示専用の素材・調合容器・完成品を識別し、source→hand→destinationへ移す。一つの物理瓶へ1〜6種類の素材をまとめ、注いだ後の空瓶で完成品を回収する。回収コマで同じ物理瓶の役割を切り替え、二重描画を防ぐ。トレーは最新の完成品を表示する枠であり、Worldの在庫ではない。

運搬時は取得終端と同じ上半身に既存歩行脚を接続し、瓶を独立描画する。停止・非表示・他タブでは時計、コマ、保持物を固定する。到着通知は次の1巡へまとめ、粗いタイマーでも経過時間の余りを次巡へ渡す。
