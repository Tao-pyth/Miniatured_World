# 保存の継続と発見履歴

v0.9.13では、設定または発見の書込みに失敗してもラボは動き続け、正常なファイルへの保存を続けます。画面下部に保存できていない対象を表示し、5秒後以降の更新時と終了時に再試行します。保存できる状態へ戻ると最新の変更を保存し、通知が消えます。

PCのロックや手動一時停止中も、Worldを進めず保存だけ再試行できます。終了時の試行が失敗した場合、未保存の変更が残ることがあります。アプリを閉じる前に通知が消えたことを確認すると、保存済みか判断できます。閉じてトレイへ格納した間は更新タイマーが止まり、再表示または終了時に試行します。

読み込めない元ファイルは、従来どおり同じ起動中は上書きしません。発見の保存をOFFにすると未保存発見の再試行も止まります。設定保存OFFの選択そのものは保存します。一時実行では設定・発見の保存先を使いません。

発見タブには、以前に保存した発見と今回の発見が重複せず並びます。過去の発見によって新しいWorldの状態や実験の反応は変わりません。保存できていない今回の発見も、アプリを閉じるまでは表示されます。

一時ファイルは保存対象ごとに最大1個を再利用します。失敗した一時ファイルを自動で元データへ戻すことはありません。データ削除と別プロセスとの同時編集調停はこの版に含みません。
