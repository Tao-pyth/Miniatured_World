# v0.8.0 RC準備版 検証手順

`v0.8.0` はMVP Release Candidate本体ではなく、MVP RC判定に必要な材料を揃えるRC準備版です。

- [ ] 実入力文字列を保存していない。
- [ ] キー入力列を保存していない。
- [ ] マウス絶対座標を保存していない。
- [ ] マウス移動軌跡を保存していない。
- [ ] クリック座標を保存していない。
- [ ] 操作対象アプリケーション名を取得していない。
- [ ] Window Titleを取得していない。
- [ ] 画面キャプチャを取得していない。
- [ ] クリップボードを取得していない。

## Windows実機確認

1. Windows 11でアプリを起動する。
2. `--activity-provider windows-global` を指定する。
3. アプリを非フォーカスにする。
4. 別アプリで英数字、記号、Space、Enter、Backspace、Modifierを入力する。
5. Worldの活動表示またはsummaryでキーボード活動が変化することを確認する。
6. マウス移動、クリック、スクロールを行う。
7. Worldの活動表示またはsummaryでポインタ活動が変化することを確認する。
8. 保存データ、ログ、画面表示に実入力文字列、キー列、座標、Window Title、クリップボード内容が含まれないことを確認する。

## GUIあり8時間安定性テスト

GUIイベントループ、Qt描画、ウィンドウ更新を含めて確認する。`--no-ui` は付けない。

確認項目:

- [ ] GUIありで8時間以上クラッシュしない。
- [ ] GUIありでメモリ使用量が単調増加し続けない。
- [ ] GUI操作、表示更新、トレイ状態が長時間後も破綻しない。
- [ ] Activity取得が停止しない。
- [ ] ログに実入力文字列、キー列、座標、Window Title、画面内容、クリップボード内容が含まれない。

## 既知制限

- `v0.8.0` はMVP RC本体ではなくRC準備版です。
- OSレベルで保証された完全クリック透過は未対応です。
- 高DPI、マルチモニター、アンチチート搭載ゲームとの互換性は完全保証しません。
- インストーラー、コード署名、自動更新は含みません。
- 外部通信、テレメトリ、クラウド同期は未実装です。
