## Windows実機確認

1. Windows 11でアプリを起動する。
2. `--activity-provider windows-global` を指定する。
3. アプリを非フォーカスにする。
4. 別アプリで英数字、記号、Space、Enter、Backspace、Modifierを入力する。
5. Worldの活動表示またはsummaryでキーボード活動が変化することを確認する。
6. マウス移動、クリック、スクロールを行う。
7. Worldの活動表示またはsummaryでポインタ活動が変化することを確認する。
8. 保存データ、ログ、画面表示に実入力文字列、キー列、座標、Window Title、クリップボード内容が含まれないことを確認する。

実行コマンド:


- 結果: completed
- frames: 28800
- elapsed_seconds: 28800
- error: 0
- RSS: 30.43MB -> 20.05MB
- CPU time: 23.578 seconds
- provider: windows-global
- 判定: `--no-ui` 8時間安定性検証は合格

短時間の事前確認:

```powershell
.\dist\MiniaturedWorld.exe --no-ui --ephemeral --activity-provider windows-global --duration-seconds 60 --tick-interval-ms 1000 --realtime --stability-log logs\v0.8.0-stability-smoke.jsonl
```

メモリ増加の高速事前確認:

```powershell
.\dist\MiniaturedWorld.exe --no-ui --ephemeral --activity-provider windows-global --duration-seconds 28800 --tick-interval-ms 1000 --stability-log logs\v0.8.0-stability-memory-fast.jsonl
```

この確認は壁時計で8時間待たずに28800フレームを処理する。正式な8時間安定性テストの代替ではなく、明らかなメモリ増加を早期に検出するための事前確認として扱う。

## 既知制限

- `v0.8.0` はMVP RC本体ではなくRC準備版です。
- OSレベルで保証された完全クリック透過は未対応です。
- 高DPI、マルチモニター、アンチチート搭載ゲームとの互換性は完全保証しません。
- インストーラー、コード署名、自動更新は含みません。
- 外部通信、テレメトリ、クラウド同期は未実装です。
