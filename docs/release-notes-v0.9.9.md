# v0.9.9 — トレイ再表示後のWorld復帰

ウィンドウを閉じてトレイから再表示したとき、絵は動くのにWorldの時間が止まる不具合を修正しました。再表示時に、同じセッションの更新タイマーを再開します。

- 一時停止、活動取得OFF、ラボ非表示を維持します。
- トレイの表示・設定・発見・アイコンの各復帰経路に対応します。
- 終了済みセッションや完了済み診断を再起動しません。
- 入力の取得方式、保存形式、Seed、画像素材は変更していません。

全160テストとWindows実機20項目が合格しました。配布exeのコード・素材照合とGUI・CLIの起動も確認しました。詳細は[検証記録](tray-reopen-verification.md)。ロック中の時間進行、8時間連続試験、FPS等を含むV1全体の合格宣言ではありません。
