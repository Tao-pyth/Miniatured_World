# v0.9.14 — 活動種類と反映量を実際の動作へ適用

キーボード・マウス移動・クリック・スクロールのON/OFFが、入力処理とラボの活動反映に作用するよう修正しました。切替前の待機入力を再ON時へ持ち越しません。

反映量0では入力のない自然な進行になり、半分では活動の特徴を半分にします。反映量0と活動取得OFFは別です。Idle信号が活動の強さへ混ざる不整合も修正しました。

全285テストとWindows配布アプリの設定操作・取得停止・強度の確認に合格しました。設定形式の移行はありません。集約間隔は時間処理と合わせて引き続き修正します。[使い方と検証範囲](activity-controls-verification.md)を参照してください。
