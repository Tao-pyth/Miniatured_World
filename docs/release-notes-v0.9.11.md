# v0.9.11 — 活動取得の停止と再開

活動取得OFF・手動一時停止・終了時に、Windowsの入力処理も休止するよう修正しました。PCロックと停止操作が重なった場合も、停止理由がすべて解消するまで取得を再開しません。

活動OFFだけならラボの時間は進みます。手動一時停止なら時間も止まります。停止前後の入力を持ち越さず、初めから活動OFFの場合は取得元を起動しません。

全187テストとWindows実機で検証。入力内容・画面・他アプリケーション情報の保存は行いません。保存形式の変更はありません。詳しくは[活動停止の使い方と検証](activity-lifecycle-verification.md)を参照してください。
