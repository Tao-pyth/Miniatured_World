# v0.9.19 — 起動設定とウィンドウ位置

通常ウィンドウの位置とサイズを保存し、次の起動で復元します。画面を外した場合も、利用できる画面へ戻れます。小さい画面では内容をスクロールして操作できます。

ログイン時の自動起動をWindowsへ登録・解除できるようにしました。明示的にONにした場合だけ登録し、失敗や状態不明を画面に表示します。設定関連の削除では登録も解除し、解除できない場合は設定を残します。

壊れたファイルの保護と正常な保存の継続、一時実行での非干渉を維持しています。旧版へ戻す場合の設定互換性とWindows側の無効化については、[使い方と検証範囲](startup-preferences-verification.md)を参照してください。

自動テストは506件合格、1件スキップ（Windowsのファイルシンボリックリンク権限）でした。Windows実機の配布exeで、登録・解除と登録コマンドからの起動、位置と保存境界の8ケース、終了・削除・破損保護・書込み回復・時間進行・休止通知とトレイ操作を確認しました。

物理的なログアウト・再ログイン、全DPI・全モニター構成の検証は実施していません。
