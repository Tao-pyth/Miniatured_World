# 保存データの保護と復旧

v0.9.12では、読み込めない設定・発見ファイルがあってもラボを起動できます。問題のあるファイルはそのまま保護し、そのファイルへの保存を止めます。正常なファイルは引き続き利用・保存します。

| 状態 | 設定の保存 | 発見の保存 |
|---|---|---|
| 設定だけ読み込めない | 一時利用・保存休止 | 通常どおり |
| 発見だけ読み込めない | 通常どおり | 新しい発見はその起動中のメモリ内のみ |
| 両方読み込めない | 一時利用・保存休止 | メモリ内のみ |

正常な設定に保存OFFの指定があれば、その指定を維持します。設定が読み込めない場合は活動取得OFFで始め、GUIでは既存の活動取得の選択を表示します。選択後の設定も、保護中の原本へ保存しません。

保存できない対象は画面下部に表示されます。CLIでも一度通知します。内容が壊れている場合だけでなく、このバージョンが扱えない保存形式・項目や読み取り権限の問題も保護対象です。通知にファイル内容やOS例外の詳細を含めません。

元ファイルは自動削除・初期化しません。正常なバックアップから復元するなどしてファイルを修復した後、アプリを再起動すると再確認します。同じ起動中は一時状態による上書きを防ぐため保護を継続します。正常な方はその間も通常の保存を行います。

この版には初期化・削除ボタンを追加していません。通常書込み中の障害に対する通知・再試行は[v0.9.13](persistence-continuity-verification.md)で対応しました。同時に別アプリが編集した場合の競合解消は別の残件です。
