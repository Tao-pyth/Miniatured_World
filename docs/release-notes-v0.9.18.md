# v0.9.18 — 終了確認とトレイ操作

「終了確認」の設定がラボ・トレイ・ウィンドウからの終了に反映されるようにしました。確認を取り消せば同じラボを続け、確定すると活動取得と更新を止めてアプリを終了します。

「トレイへ最小化」がONの場合、閉じる操作でラボを終了せずトレイへ移します。ラボとログは続き、トレイから同じセッションへ戻れます。利用できないトレイへ隠れて操作不能になることを防ぎます。

時間指定の自動終了やOS終了は確認で妨げません。壊れたファイルの保護、正常な設定・発見の保存継続、削除済みデータの保護は維持しています。[操作と検証範囲](exit-lifecycle-verification.md)を参照してください。

全自動テスト428件成功、Windows配布版の終了・取消・トレイ復帰7経路を確認しました。各終了で親子プロセスが終了し、取消ではログが続き、最小化から同じラボへ戻れることを検証しています。ファイルのシンボリックリンク作成1件はWindows権限によりスキップしています。
