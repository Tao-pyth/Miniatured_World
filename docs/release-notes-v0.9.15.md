# v0.9.15 — 活動の集約間隔とWorldの進行を整合

集約間隔100〜5000msが実際の動作へ反映されるようになりました。同じ活動の重複使用を防ぎ、Worldは1秒刻みで進めます。更新間隔を短くしてもWorldやDemo入力が何倍も増えることはありません。

種類や周期の変更、休止・復帰で未反映の活動を持ち越しません。GUIで途中の周期を変えても安定性実行の時間予算を維持し、CLIも内部更新を適切に細分化します。

設定形式の移行はありません。旧版の重複反映と時計の扱いを修正したため、旧版との完全な結果一致は保証しません。[使い方と検証](activity-timing-verification.md)を参照してください。

自動テスト344件と、Windows配布アプリの時間進行21ケース、設定画面の操作、保存保護・保存回復、休止通知とトレイ復帰を確認しました。壊れたファイルを保護し、正常な設定・発見は保存し続ける方針を維持しています。
