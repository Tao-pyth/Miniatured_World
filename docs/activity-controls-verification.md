# 活動設定の使い方と検証

「設定 → 活動」でキーボード、マウス移動、クリック、スクロールを個別に選べます。4項目は独立しています。OFFにした種類はラボの活動へ反映せず、再びONにしてもOFF前の待機入力を持ち越しません。全種類OFFでもラボは自然に進みます。

Windowsの実活動取得では、無効なキーボードやマウス系全体の入力本文を取得せず、マウスの項目は必要なものだけカテゴリ化します。OSからの通知は登録されたままですが、全種類OFFではRaw APIを呼びません。

「反映量」は活動をラボへ反映する強さです。最大は従来どおり、半分では活動の各特徴を半分にし、0では自然な進行だけになります。入力取得を止めたい場合は「有効」をOFFにしてください。反映量0だけでは取得を停止しません。

設定は保存後の起動にも適用します。保存OFF・読込み保護・書込み失敗の通知と再試行は従来どおりです。ロックや一時停止中に種類を変えても、勝手に取得やWorldを再開しません。

集約間隔はまだ実適用されていません。重複反映を防ぐ時間処理と合わせて別途修正します。この版で全設定やアプリ全体の完成を宣言するものではありません。
