# v0.9.6 GUI一時実行の保存境界

`--ephemeral` を指定したとき、GUI入口が保存先 `None` を既定パスに置き換える不具合を修正した。保存先はCLIで解決し、QtからRuntimeへそのまま渡す。

## 回帰検査

`tests/integration/test_gui_persistence.py` は実際の子プロセスでGUIを起動する。修正前は「一時実行が既定ディレクトリを作らない」の検査が失敗し、修正後は7ケースすべて合格した。

- 既定/明示保存先に既存データがない場合、一時GUIはディレクトリを作らない。
- 両保存先に壊れたテスト用JSONがある場合も、一時GUIは読み込まず正常終了し、全ファイルの内容と更新時刻を維持する。
- 通常GUIは選んだ保存先だけへ設定・発見を保存する。
- `--ephemeral` は `--data-root` より優先する。UIなしの一時実行も維持する。
- 明示した診断ログは出力し、完了イベントまで確認する。

## 実機・配布検証

すべての起動試験で `MINIATURED_WORLD_DATA_DIR` を専用の検査先へ向ける。ユーザーの通常の保存先を読み書きしない。全113テストが合格。wheelのコード/素材とソース、exeの184素材とソースのバイト一致を確認した。

Windowsネイティブの単体exeで以下を確認した。

| ケース | 結果 |
| --- | --- |
| 一時GUI・保存先なし | 15.303秒、15フレーム正常終了、既定/指定データディレクトリを作らない |
| 一時GUI・壊れた既存JSON | 正常終了、両保存先の4ファイルの内容と更新時刻が不変 |
| 通常GUI・既定保存先 | 設定/発見を既定先だけへ保存 |
| 通常GUI・明示保存先 | 設定/発見を明示先だけへ保存 |
| 一時CLI | 5フレーム正常終了、データディレクトリを作らない |

exe SHA256: `7755da687e9ba037349cb1e0645046b96e5f75de18aaaf24532162e2eeb138aa`（52,544,383 bytes）。公開後はexeとSHA256ファイルを再取得して一致を確認し、同じ5ケースを再実行する。公開後の結果はOODA Act正本へ記録する。

原画・184素材・アニメーションは変更なし。素材manifestのv0.9.5は素材セットの版を表し、アプリの版はv0.9.6。過去のGUI一時実行による既存データの変更有無は、この検査から遡って判定できない。
