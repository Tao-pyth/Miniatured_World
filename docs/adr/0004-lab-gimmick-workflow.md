# ADR 0004: 道具ごとの配置と表示専用の作業連携

状態: 採用（v0.9.2）

## 背景

v0.9.1は人物と釜を固定位置へ描画し、本・素材かごの状態や作業位置を持たなかった。ユーザーから独立した道具を近接配置し、素材到着→本確認→調合→完成品配置を連携させる指示があった。

## 判断

`LabLayout`に舞台上の配置と人物作業点、`GimmickState`に各道具の表示状態を持たせる。既存`LabAnimation`の描画時計で作業順序を管理する。描画は`lab_paint.py`で接地点の奥から並べる。

新規素材の増分で一巡を開始し、連続到着は次の一巡へまとめる。作業中の毎秒通知でアニメーションが先頭へ戻ることや、無制限の作業キューを避ける。停止/非表示中に時計を進めず、再表示で追いつき動作を行わない。

## 影響

Worldの素材消費・発見生成は変更しない。完成品小瓶は表示演出であり、永続的な製品/レシピモデルを追加しない。保持するのは既存のサニタイズ済みスナップショット、時間、限定した素材識別子のみ。

共通舞台で座標を持つが、取得したユーザーのマウス座標とは無関係。Activity Provider・Privacy Filter・Persistenceへ依存を追加しない。

自由歩行/経路探索や汎用ギミックエンジンは導入しない。必要になった時点で別のOODA契約を定める。
