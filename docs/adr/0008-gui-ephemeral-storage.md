# ADR 0008: 保存先を起動入口で一度だけ解決する

状態: 採用（v0.9.6）

`--ephemeral` はCLI入口で保存先を `None` にするが、GUI入口が `data_root or default_data_root()` で既定パスへ戻していた。その結果、GUIの一時実行で設定・発見の読み書きが発生した。

保存先はCLI入口で解決し、Qt入口は渡された `Path` / `None` をそのままRuntimeへ渡す。内部関数 `run_qt_app(data_root=None)` はメモリのみで動作する。通常のCLI起動は従来どおり既定パス、`--data-root` があれば指定パスを使う。両オプションがあれば `--ephemeral` を優先する。

設定/発見の保存形式は変更しない。明示された `--stability-log` は診断出力として別に扱う。過去の一時実行による影響は不明なので、既存データの自動削除や復元はしない。

テストは実際の子プロセスでCLI→GUI→Runtimeを通し、新規保存先を作らないこと、壊れた既存JSONにも触れないこと、通常起動は保存することを検査する。既定保存先を専用ディレクトリへ上書きし、ユーザーのデータを検査対象にしない。
