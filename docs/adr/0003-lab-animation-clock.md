# ADR 0003: ラボ描画時計と固定舞台

## 状態

採用、v0.9.1。

## 背景

活動スナップショット更新でコマを進めると既定周期では1fpsになり、提供された8コマ素材を適切に再生できない。背景のみの中央トリミングは前景の接地位置をずらす。また、永続する発見集合を成功条件にすると成功表示が固定される。

## 決定

表示専用の `LabAnimation` がサニタイズ済みスナップショット間の新規発見と経過時間を保持する。Qt描画タイマーを活動集約から分離し、30Hzを上限として再描画する。釜は125msごとにコマを進める。成功は新規差分に対し3.2秒だけ表示する。

背景と前景は1280×853の同じ舞台座標を使い、全景が収まる倍率と余白を適用する。素材は共通キャンバスと接地基準を持ち、蒸気の高さで釜のサイズを変えない。

## 影響

シミュレーション乱数・経過時間・入力集約・保存形式は変更しない。非表示や一時停止で描画タイマーも停止する。スナップショットと表示時間だけで描画テストを再現できる。提供素材の切り出しとプレビュー生成手順は [制作仕様](../lab-asset-spec.md) に残す。

## 代替案

活動更新の高速化はシミュレーションと入力層へ影響するため採用しない。全シーンの動画化は素材や発見への反応を失うため採用しない。
