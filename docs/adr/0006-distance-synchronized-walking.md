# ADR 0006: 歩行を移動距離へ同期する

状態: 採用（v0.9.4）

## 背景

道具ごとの作業位置へ450msで立ち絵を滑らせていた。歩行コマを時間だけで再生すると、異なる距離で足が空回りする。

## 判断

既存の作業経路と1巡11秒を保ち、舞台上80px/秒の等速移動に置き換える。48px進むごとに8コマが一巡する。右への移動では左向き素材を反転する。移動が完了すると作業ポーズへ戻る。

`phase_progress`は従来の段階全体の進捗とし、`action_progress`は到着後の作業時間だけを0〜1へ正規化する。移動中は後者を0にし、道具の作業状態と素材エフェクトを開始しない。短い移動に8コマ全てを詰め込まない。

`LabAnimation`の表示時計を唯一の時間源とする。タイマーの刻み幅にかかわらず同じ時間で同じ位置・姿勢になる。一時停止・非表示では時計を止め、歩行中の姿勢を保持する。World/入力/保存の状態は増やさない。

## 素材と制約

既存128×128、接地y=120、64色、二値alphaへ歩行原画を整形する。顔・帽子を共通化し、後半の脚は前後関係を明暗で区別する。原画と変換を保存する。

自由散策・経路探索は導入しない。作業位置を大きく離す変更では、現在の段階時間内に到着して作業できるかを再検討する。
