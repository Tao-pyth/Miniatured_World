# ADR 0019: 診断ログの所有と再ロード可能なキャッシュ

状態: 採用。OODA baseline v0.9.16 / Decide001、対象v0.9.17。

任意パスへ出力した診断ログはdata-rootと独立し、従来は過去ログの所在を再確認する情報がなかった。設定・発見だけの消去を全データと扱わず、ログの所有一覧と過去ログの明示選択を追加する。

LogRegistryは通常実行時に、正規化した絶対パスと先頭行SHA256をlog-index.jsonへ保存する。Storeの既存の原子的保存、ファイル単位の読込保護、失敗時再試行と削除境界を再利用する。欠落は旧版との互換状態として扱い、空一覧を通常起動で自動生成しない。新ログのアプリ識別子とschemaは先頭行への追加項目であり、旧ログも既存start構造を確認して選択できる。

削除は確認された一覧に限定し、保存先の正規化と先頭行識別を再検証する。リンクとジャンクションによる保存先変更を拒否し、未知のフォルダを探索しない。出力中writerを閉じ、既存の_closedガードで再生成を抑止する。失敗項目を一覧に残し、壊れた一覧は自動で消さず全体完了を報告しない。

キャッシュはメモリ内の画像・動作定義とQt画像cacheである。同梱素材の原本を消さず、読み直しが可能かを確認して表示資産を更新する。World/seed/アニメーション時計を初期化しない。存在しないdisk cacheや自動ログ生成は追加しない。

全データ操作は対象別の結果を合成する。未登録の過去ログは確認画面から追加できる。操作の取り消し、ephemeral、障害時の原本保護を保つ。複数プロセス間の排他と所在不明の任意ファイル自動探索は扱わない。
