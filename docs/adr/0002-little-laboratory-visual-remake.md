# ADR 0002: 小さなラボラトリー表示リメイク

## 状態

採用

## 背景

V0.8.2までに、活動取得、非干渉表示、設定、発見保存、配布ビルドの足場は整った。一方で、綺麗な箱庭世界、地形、植物群、生物群をMVP品質で描くには、視覚品質と制作コストのリスクが大きい。

ユーザー検討により、プロダクト表現を `World/Garden` から `Lab/Experiment` へ移し、名称を「小さなラボラトリー」とする方針を採用した。モチーフとして、錬金術師の女の子、錬金釜、素材、実験、観察、記録を扱う。

## 決定

初期V0.9では、既存の `Activity -> Material -> Event -> Discovery` 基盤を維持したまま、ユーザー向け表示を小さなラボへ置き換える。

表示は以下のレイヤーで扱う。

1. 背景: 小さなラボの基準背景画像。
2. ギミック: 錬金釜。
3. キャラクター: 錬金術師の女の子。
4. エフェクト: 素材流入、反応光、煙。
5. UI: 活動状態、素材数、発見通知。

初期キャラクター状態は `idle`、`work`、`success`、`failure`、`rest` とする。錬金釜状態は `cauldron_idle`、`cauldron_receive`、`cauldron_react`、`cauldron_success`、`cauldron_failure` とする。

## 影響

- 内部World Simulationは即時改名しない。安定した活動・素材・発見基盤を維持する。
- UI文言とユーザー向け説明は「ワールド」中心から「ラボ」中心へ寄せる。
- 背景にキャラクターや錬金釜を焼き込まず、別レイヤーで描画する。
- 入力文字列、Window Title、画面内容、クリップボード内容など、作業内容を示す情報は素材や実験内容へ使わない。

## 代替案

- 箱庭描写を継続する: 視覚品質の要求が高く、MVP範囲が膨らむため不採用。
- 背景にキャラクターと錬金釜を焼き込む: 一枚絵としては作りやすいが、状態差分と拡張性が落ちるため不採用。
- 内部モデル名を全面改名する: ユーザー向け価値に直結しない破壊的変更が増えるため、初期V0.9では不採用。
