# ADR 0011: 再表示時のWorldタイマー復帰

- 状態: 採用
- 対象: v0.9.9
- 日付: 2026-09-11

## 問題

Windows実機で、ウィンドウを閉じてトレイから再表示すると、アニメーションだけが動きWorld時間が止まる。`closeEvent` がWorldタイマーを停止する一方、トレイの各復帰操作は `showNormal` のみで、Worldタイマーを再開していなかった。独立した3回すべてで再現した。

## 判断

MainWindowの `showEvent` で現在のRuntimeスナップショットをラボ表示へ反映し、初期化済み・稼働中・未完了で停止しているタイマーだけを再開する。トレイの表示・設定・発見・アイコンからの復帰を共通の表示ライフサイクルへ集約する。

タイマーが動いている場合は再起動しない。再表示でセッションやSeedを作り直さず、手動一時停止・活動取得OFF・World非表示を維持する。終了済みRuntimeや時間指定の完了状態は再開しない。古い描画スナップショットを最新状態へ更新することで、終了済みセッションの描画だけが再開することも防ぐ。

## 維持する境界

閉じている間のWorld停止、トレイの「隠す」中の継続、明示終了、診断ログの閉じる操作による中止を維持する。中止された診断ログへ再表示後の結果を書き足さない。閉じるを常にhideへ置き換える案や、各トレイ処理への重複修正は採用しない。

保存形式・活動取得・素材・World内部のルールは変更しない。ロック中の時間停止、minimize_to_tray等の未接続設定全般、長時間/FPS保証は別のOODAで扱う。

## 検証

既存148テストに12ケースを追加し、実イベントループで時間進行・状態保持・終了済み実行・診断中止・各復帰入口を検証する。修正前に失敗し、修正後に全160テストが合格した。[実機・配布確認](../tray-reopen-verification.md)も実施する。
