# ADR 0010: GUI・CLIで起動ごとにSeedを生成する

2026-09-10、v0.9.8。採用。

仕様35.3はセッションごとのSeed生成を求めるが、CLI入口はGUI/CLIとも20260825固定だった。ユーザーは両入口とも毎回生成し、再現には明示 `--seed` を使う方針を選択した。

argparseの省略値をNoneにし、引数検査後に `secrets.randbits(64)` を一回だけ呼ぶ。OSの乱数源を利用し、入力内容、日付、活動量、保存設定からは生成しない。解決済み値をGUI/Runtimeへ渡し、GUIが利用できずCLIへ切り替わっても再生成しない。明示0・負数もそのまま渡す。

World内部のRandomProvider、シミュレーション、永続化形式は変更しない。同じseed・活動入力・コンテンツでの再現性は維持する。seedを変えても限られた傾向・特性が同じになる場合があるため、生成の検査は表示の差に依存しない。

CLIの省略時固定値を維持する案は本人が不採用。旧版の初期条件や固定された検証を必要とする利用者は `--seed 20260825` を付ける。seed履歴、新しいGUI設定欄、日付固定ルールは追加しない。
