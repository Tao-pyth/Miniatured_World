# v0.9.13 — 保存の再試行と発見履歴

設定・発見の書込みが失敗しても、ラボと正常なファイルの保存を続けます。画面で未保存の対象をお知らせし、5秒後以降と終了時に最新の変更を再試行します。読み込めない元ファイルの保護は維持します。

発見タブに、過去に保存した発見も表示するようにしました。新しいWorldの状態や新規発見の反応は変えません。

全239テストに合格。Windowsの実ファイル占有で保存継続と回復、画面の通知・履歴表示を検証しました。保存形式の移行はありません。[保存の継続と発見履歴](persistence-continuity-verification.md)に使い方と検証範囲を記載しています。
