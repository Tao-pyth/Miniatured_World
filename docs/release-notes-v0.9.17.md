# v0.9.17 — ログ・キャッシュ・全データの削除

「設定 → データ」にログ、過去ログの選択、キャッシュ、すべてのアプリデータの削除を追加しました。削除前に対象を確認し、失敗した対象は個別に表示します。未登録の過去ログも確認画面から追加できます。

通常実行で出力した診断ログの保存先を管理し、別起動からも削除できます。出力を停止してから削除するため、同じ実行の後続更新でログが戻ることはありません。キャッシュは元の画像を消さずに読み直し、ラボの状態を維持します。

設定・発見の形式は変わりません。一時実行では既存保存先やログ管理一覧へ触れません。[使い方と確認範囲](remaining-data-verification.md)を参照してください。

全自動テスト397件とWindows配布アプリの削除操作6経路を確認しました。破損ファイルの原本保護、正常な設定・発見の保存継続、使用中ログの再操作、ラボの継続を含みます。ファイルのシンボリックリンク作成1件はWindows権限によりスキップし、ジャンクション変更は実機で検証しました。
