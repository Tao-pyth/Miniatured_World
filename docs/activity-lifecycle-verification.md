# 活動取得の停止と再開

v0.9.11では、活動取得をOFFにするとWindows側の入力解析も休止します。一時停止・PCロック・終了と重なった場合は、停止理由がすべて解消するまで再開しません。

| 操作・状態 | 活動取得 | ラボの時間 |
|---|---|---|
| 活動OFF | 休止 | 進む |
| 手動一時停止 | 休止 | 止まる |
| PCロック・OS休止 | 休止 | 止まる |
| ラボ非表示のみ | 元の取得設定を維持 | 従来の表示制御に従う |
| 終了 | 停止 | 止まる |

停止直前と停止中の入力を、再開時にまとめて反映しません。取得OFFで起動した場合、Windowsの取得元は取得をONにするまで生成されません。保存データの移行は不要です。
